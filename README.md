# Rise of Magadh: A Mauryan Epic

An interactive journey through the birth, rise, and legacy of one of history's greatest empires.

![Mauryan Empire Banner](https://cihs.blog/wp-content/uploads/2024/08/akhand-bharat-manifestation-of-spiritual-nationalism-.jpg)

## Tech Stack

### Frontend
- **React 18.3.1** - Core UI library
- **TypeScript** - Type safety and enhanced developer experience
- **Tailwind CSS** - Utility-first CSS framework for styling
- **Lucide React** - Modern icon library
- **Vite** - Next-generation frontend tooling

### Development Tools
- **ESLint** - Code linting and style enforcement
- **PostCSS** - CSS transformations with Autoprefixer
- **TypeScript ESLint** - TypeScript-specific linting rules

## Project Structure

```
src/
├── components/         # Reusable UI components
├── sections/          # Major page sections
├── data/             # Static data and content
└── App.tsx           # Main application component
```

### Key Components
- `FigureCard` - Displays historical figures with their achievements
- `TimelineEvent` - Interactive timeline events
- `Navbar` - Responsive navigation with smooth scrolling

### Major Sections
- Hero - Landing page with dramatic imagery
- About - Overview of the Mauryan Empire
- Timeline - Interactive chronological events
- Key Figures - Prominent historical personalities
- Mauryan Map - Territory visualization
- Dharma - Ashoka's edicts and principles
- Legacy - Historical impact and influence

## Getting Started

1. Clone the repository
```bash
git clone <repository-url>
```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```
